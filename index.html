Tipuri de variabile în C++

    signed (normal): negativ si pozitiv, valori mai mici; unsigned: 0 si pozitive, vslori mai mari (duble)

  1. int → număr întreg
    Exemplu: int varsta = 18; -2,147,483,648 | 2,147,483,647
  2. short → număr întreg mic
    Exemplu: short x = 100; -32,768 | 32,767
  3. long → număr întreg mare
    Exemplu: long populatie = 1000000; -2,147,483,648 | 2,147,483,647
  4. long long → număr foarte mare
    Exemplu: long long stele = 999999999; -9,223,372,036,854,775,808 | 9,223,372,036,854,775,807
  5. float → număr zecimal
    Exemplu: float nota = 9.5f; -3.4e38 | 3.4e38
  6. double → număr zecimal mai precis
    Exemplu: double pi = 3.141592; -1.7e308 | 1.7e308
  7. long double → precizie foarte mare
    Exemplu: long double x = 3.1415926535; -1.1e4932 | 1.1e4932
  8. char → un singur caracter
    Exemplu: char litera = 'A'; -128 | 127
  9. string → text
    Exemplu: string nume = "Dragos";
  10. bool → adevărat sau fals
    Exemplu: bool online = true;
  11. unsigned int → doar valori pozitive
    Exemplu: unsigned int bani = 500;
  12. const → valoare constantă
    Exemplu: const int zile = 7;
  13. auto → tip detectat automat
    Exemplu: auto pret = 19.99;
  14. array → listă de valori
    Exemplu: int note[3] = {10, 9, 8};
  15. pointer → adresa unei variabile
    Exemplu: int* p = &x;
  16. nullptr → pointer gol
    Exemplu: int* p = nullptr;
  17. reference → alias pentru o variabilă
    Exemplu: int& r = x;
  18. enum → valori fixe
    Exemplu: enum Zi {Luni, Marti, Miercuri};
  19. struct → grup de variabile
    Exemplu: 
    struct Elev {
    string nume;
    int varsta;
};
